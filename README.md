# Survikit · mapas sin internet

Mapas vectoriales (.pmtiles) que descarga la app [Survikit](https://survikit.app) para usarlos sin conexión.
Cada país es una *release* y cada archivo, una provincia o región.

Datos: © colaboradores de [OpenStreetMap](https://www.openstreetmap.org/copyright) (ODbL), teselas de [Protomaps](https://protomaps.com).

Offline vector maps (.pmtiles) downloaded by the Survikit app. Data © OpenStreetMap contributors (ODbL), tiles by Protomaps.
